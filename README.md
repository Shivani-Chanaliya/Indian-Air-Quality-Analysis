📊 Indian-Air-Quality-Analysis 

🚀 Project Overview

This project focuses on RFM (Recency, Frequency, Monetary) Analysis, a customer segmentation technique used to understand customer purchasing behaviour.

The project analyses transactional data and segments customers based on their purchasing patterns. It is built using Python and deployed as an interactive web application using Streamlit.

🎯 Project Objectives

- Analyse customer purchasing behaviour.
- Identify valuable and frequent customers.
- Understand customer spending patterns.
- Segment customers using RFM metrics.

🛠️ Technologies Used

- Python – Programming language
- Pandas – Data manipulation and analysis
- NumPy – Numerical operations
- Streamlit – Web application and dashboard deployment
- Data Visualization – Visual representation of analytical results

📌 Understanding RFM Analysis

RFM stands for:

Metric| Description
Recency| How recently a customer made a purchase
Frequency| How frequently a customer makes purchases
Monetary| How much money a customer spends

These three metrics help businesses understand customer value and purchasing behaviour.

💻 Run Locally

Follow these steps to run the project on your computer.

1. Clone the repository

git clone https://github.com/Shivani-Chanaliya/Indian-Air-Quality-Analysis.git

2. Navigate to the project folder

Open the folder containing "RFM_Analysis.py".

3. Install dependencies

pip install -r requirements.txt

4. Run the Streamlit application

streamlit run RFM_Analysis.py
